# ⏰ Digital Clock

A simple and responsive Digital Clock built using **HTML, CSS, and JavaScript**. It displays the current time in real time with hours, minutes, seconds, and AM/PM format.

## 🚀 Features

- Displays real-time clock.
- 12-hour time format (AM/PM).
- Updates every second automatically.
- Clean and simple user interface.
- Responsive design.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📚 What I Learned

- JavaScript `Date()` object.
- Functions and variables.
- DOM manipulation.
- `setInterval()` method.
- Updating HTML elements dynamically.
